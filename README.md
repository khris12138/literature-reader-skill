# Literature Reader

一个专为阅读和解释学术文献设计的Claude Code skill，特别适合社会学及相关社会科学领域的论文。

## 功能特点

- **完整摘要翻译**：将论文标题、作者信息和摘要翻译成自然流畅的中文
- **核心问题提炼**：用一句话抓住论文的真正智识问题
- **教授式讲解**：用清晰的要点解释作者如何回答核心问题（限3000字）
- **生活化故事**：用日常场景帮助理解论文的核心观点
- **多篇对比**：可以同时解读多篇论文并进行学术点评

## 使用方法

在Claude Code中调用：

```
/literature-reader "path/to/paper.pdf"
```

或直接在对话中提供PDF文件路径。

## 平台兼容性

### Claude Code（推荐）
完全支持，使用 `pdftotext` 命令直接提取PDF文本。

### 其他AI平台（Kimi、DeepSeek、ChatGPT等）
如果平台有PDF读取能力，skill会自动尝试使用。如果没有，会提示你提供文本版本。

## 输出格式

每篇论文按以下四步输出：

1. **题目、作者信息与摘要翻译** - 完整准确的中文翻译
2. **文章的核心问题** - 一句话概括（以"？"结尾）
3. **教授讲解** - 3-5个要点说明如何回答核心问题
4. **生活化故事** - 400-600字的日常场景类比

## 设计理念

- **从文本出发**：必须先提取实际PDF文本，禁止根据标题猜测
- **证据意识**：区分作者的研究发现、研究方法和教学阐释
- **中文优先**：专业术语以中文解释，必要时标注英文原文
- **学生友好**：像资深社会学教授一样耐心、清晰地讲解

## 注意事项

⚠️ **必须验证文本提取成功**：如果只看到 "PDF file read: filename.pdf"，说明提取失败，需要重新提取或请用户提供文本版本。

⚠️ **不要编造内容**：如果PDF无法读取，明确告知用户，不要根据标题推测内容。

## 示例

```bash
/literature-reader "~/papers/bourdieu_1986_forms_of_capital.pdf"
```

输出会包含完整的四步解读，帮助快速理解论文核心论点。
